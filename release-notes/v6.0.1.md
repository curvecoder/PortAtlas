PortAtlas 6.0.1 fixes the section headers of the graphical interface and adds a user guide for it. The command line, the audit log, the output formats and the configuration keys do not change.

## Fixes

- **Graphical interface**: the command forms headed two sections with internal names. The map rendering section read `MapRendering` and the last section `Advanced`. They now read "Map rendering" and "Other options".

## Documentation

- **[Use the graphical interface](https://github.com/curvecoder/PortAtlas/blob/main/docs/how-to/use-the-graphical-interface.md)**: a new guide that covers installing the interface beside the command line, filling in a command form, running a command, saving and loading profiles, and changing the theme.
- **[Architecture](https://github.com/curvecoder/PortAtlas/blob/main/docs/explanation/architecture.md)**: the log rewrites at start and stop, the projects of the solution, the commands that work from the logs, and what each command writes or sends over the network.
- The command lines and configuration examples of the documentation are now checked against the program by the test suite.

## Frameworks

Unchanged: ProcessForge 1.3.1, SocketForge 2.1.1, FileForge.Core 1.4.1, TopologyForge 1.13.0.
