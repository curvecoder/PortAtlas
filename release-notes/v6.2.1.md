PortAtlas 6.2.1 sorts the addresses of the `export rules` matrices by value and completes the sample configuration file. The audit log, the command line and the configuration keys do not change.

## Fixes

- **Address order in the rule matrices**: the five matrices of `export rules` sorted their addresses as text, so `192.168.1.10` came before `192.168.1.2`, and the rule numbers followed that order. Addresses are now sorted by value, IPv4 before IPv6, and the other names (address groups, `Any`) come after them in text order. The rows and their content do not change, only their order and numbers.
- **Sample configuration file**: the `portatlas.json` shipped beside the executable did not list the `AddressGroups` key added in 6.2.0. It now lists every key that `config init` writes.
- **Null address group entry**: a `null` entry in an `AddressGroups` list was reported as `''`. The error now names it as a null entry, with its group.

## Frameworks

Unchanged: ProcessForge 1.3.1, SocketForge 2.1.1, FileForge.Core 1.4.1, TopologyForge 1.13.0.
