PortAtlas 6.1.0 adds a command line option for the RDAP timeout and fixes the resume of an audit log written with another separator, the DNS cache saves, the reading of NDJSON logs by `resolve` and the time format of the dashboard. The audit log, the output formats and the configuration keys do not change.

## New

- **`--rdap-timeout-ms`**: `audit`, `resolve` and `lookup` accept the RDAP timeout on the command line, as `--dns-timeout-ms` does for DNS. The option overrides the `RdapTimeoutMs` key (4000 ms by default, minimum 1). The graphical interface offers it in the command forms, and the `TIMEOUT` hint of `lookup` names it.

## Fixes

- **Resume after a change of `CsvDelimiter`**: the audit read its own log back with the configured separator, so changing `CsvDelimiter` stopped the resume with an error about an unreadable `FirstSeenUtc` value on the header line. The log is now read with the separator found on its first line and rewritten at start with the configured one.
- **DNS cache saves**: a save scheduled after a resolution could write the cache at the same time as the final save of the audit, or after it with an older state, and lose the last names. Saves now run one at a time, and nothing is written once the final save is done.
- **NDJSON keys read by `resolve`**: `export rules` and `export ndjson` read the property names of an NDJSON log in any case, while `resolve` looked for `remoteIp` and `remoteHostName` as written. A log with `RemoteIp` keys was neither resolved nor named. The keys are now read in any case, and the host name is written under the spelling the line already uses. A line holding the same key twice with a different case is copied unchanged.
- **Dashboard times**: the header, the `TIME` column and the console messages of the continuous audit used the time separator of the current culture, so a culture that separates hours with dots changed their look. They are now always written as `HH:mm:ss`.

## Frameworks

Unchanged: ProcessForge 1.3.1, SocketForge 2.1.1, FileForge.Core 1.4.1, TopologyForge 1.13.0.
